# outputs/artifacts/

Place all non-code evidence here before zipping your submission. This includes:

- Screenshots or exported results of your `pytest` run (e.g. `test_results.txt`)
- Exported CSV/screenshot of your `eda.data_quality_report(...)` output
- Exported CSV/screenshot of your `eda.multi_driver_ranking(...)` output
- Any chart, diagram, or exploratory plot you generated
- Any other proof that your analysis was actually executed and validated against the
  provided data, not just written up from assumption

This folder is empty in the starter package on purpose -- populate it as you complete
each Learner Task. See the Deliverables table in the Assignment Document for what's
required here specifically.
